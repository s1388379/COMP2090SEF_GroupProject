# Title: Clinic Management System #
This is a simple OOP-based system we created to help manage Patients, nurses and doctors inside a Hospital. Seldom, when under major emergency situations, it can help to triage patients depending on the urgency of their injuries and help process them through A&E quicker

This system currently has around 3 programs, focusing on patients' personal details, doctors' information, and a system for storing appointment data.
